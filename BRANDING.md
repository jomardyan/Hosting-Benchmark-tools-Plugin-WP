# LS Hosting Benchmarks branding

Canonical plugin display name: **LS Hosting Benchmarks**.

Proposed GitHub repository name: **LS-hosting-benchmarks**. The repository rename is a manual owner action; current GitHub URLs are preserved until it happens.

This is source-only branding work. Plugin and schema versions remain unchanged; increment the version when distributing a new release so existing installations can receive an update notification.

Public plugin headers, current documentation, menu labels and applicable package/translation metadata use the LS name. Company and author attribution remain unchanged. Historical audit reports and release archives can retain former names.

## Compatibility

Plugin folders and file basenames, PHP namespaces/classes/functions, text domains, options, database tables, REST routes, action/filter IDs, license product IDs and update endpoints retain their existing identities. The administration menu remains `wp-hosting-benchmark`, with the original `hosting-benchmark` submenu screen prefix.

A display-name change is not a WordPress.org slug migration. GitHub renaming does not require changing installed WordPress identities. After the owner renames the repository, update canonical repository links and checkout remotes as a separate reviewed step; do not create links to an uncreated repository now.

The descriptive name uses the LS brand first and readable functional terms. It is not a guarantee of WordPress.org approval, search ranking, trademark clearance or slug availability.
